# 蛇对蛇 / SNAKE DUEL

参考《绝区零》金手指电玩店的独立 Canvas 街机复刻。无引擎、无运行时依赖，无网络资源请求。

## 运行

直接在浏览器中打开 `index.html`，或安装 Node.js 后在此目录执行：

```sh
npm start
```

访问 `http://127.0.0.1:4173`。可用 `PORT` 环境变量更改端口。

`dist/index.html` 是已打包的离线单文件版本，可单独复制到其他设备打开。修改源文件后执行 `npm run build` 重新生成。

## 操作

| 操作 | 键盘 | 触屏 |
| --- | --- | --- |
| 转向 | 方向键 / WASD | 左侧摇杆 / 棋盘滑动 |
| 爆冲 | 按住 J / 空格 | 按住右侧 BOOST |
| 暂停 | P / Esc | 棋盘下方暂停按钮 |
| 开始 / 继续 | Enter | 黄色开始按钮 |
| 重开 | R | 暂停后选择重新开始 |

支持音效开关、全屏、失焦自动暂停、本机最高分。触屏同时支持摇杆与爆冲多点操作。

## 已实现规则

- **经典对决**：180 秒，一名玩家对两名 AI。得分保留，阵亡后 3 秒在安全位置以 8 节身体复活，并获得 2 秒保护。
- **小队热斗**：45 秒，玩家与蓝色 AI 对抗紫色、粉色 AI。5 秒复活；结束时按场上存活蛇的队伍总长度判胜。同队蛇可互相穿过。
- **爆冲**：移动间隔从 115ms 降为 51ms；每 280ms 消耗 1 节，长度不大于 6 时停止。带有速度粒子、发光和能量显示。
- **魔豆**：增加 1 节；基础 100 分，每次吞噬后下一个分值提高 10%。单个魔豆最高 100,000 分，总分上限 999,999,999。
- **钻石**：增加 5 节，奖励当前魔豆分值的 12 倍。
- **无敌星**：增加 2 节，当前魔豆分值的 20 倍，8 秒彩虹无敌。可用头部撞碎敌蛇和障碍，撞墙会反弹。
- **围杀**：头部撞到敌蛇身体、墙、障碍或爆雷即阵亡。自己的身体可穿过。双方同时迎头相撞会同时阵亡，无敌与复活保护另行判定。
- **掉落**：阵亡身体碎成可收集的魔豆，22 秒后消失；爆冲也可能在尾部留下少量 9 秒掉落。
- **风险**：游走爆雷、固定障碍、后期带预警的新障碍。
- **AI**：抢食、道路探测、空间搜索、预测敌方路线、短暂爆冲截路。

这是根据用户给定规则与截图制作的玩法复刻；小队模式的其他三条蛇由 AI 控制，未实现在线联机。时间、速度、得分与道具刷新率为演示调校值。

## 文件结构

- `engine.js`：不依赖 DOM 的 `Snake`、`Game`、固定时间步模拟、AI、碰撞与道具生成。
- `renderer.js`：Canvas 网格、方块蛇、彩虹尾部、道具、爆冲粒子与积分浮字。
- `app.js`：键盘、触屏、界面状态、数码计分器、音效与本机存档。
- `styles.css`：街机外框、响应式布局与移动端摇杆。
- `tests/engine.test.cjs`：使用 Node 内置测试器验证游戏规则与完整 AI 对局。

```sh
npm test
```
